The CONTENIDO page listing chapters and their subsections.

- Consumer provides `items`: `{ number, title, page, level }`. Chapters use Roman numerals and uppercase titles; level 2 entries use `a.`, `b.` and sentence case.
- Set in the light `contents-title` / `contents-entry` styles in `slate-deep`; a dotted `rule-muted` leader runs to the page number.
